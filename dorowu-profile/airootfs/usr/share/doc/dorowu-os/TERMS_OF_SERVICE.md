## 1. Description of the System

Dorowu OS is an open-source operating system distribution based on Arch Linux, featuring:
- KDE Plasma 6 desktop environment
- Calamares graphical system installer
- Linux Kernel 6.x and official Arch Linux package repositories
- Built-in Dorowu OS AI Assistant desktop application powered by modern AI APIs
- Automated ISO builds maintained via GitHub Actions (`.github/workflows/build-x86_64.yml`)

The Dorowu OS AI Assistant provides interactive system administration guidance, command troubleshooting, bash scripting assistance, package management support, and general computing companion services.
